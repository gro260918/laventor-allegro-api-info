# Laventor Allegro API

Public information page for the **Laventor Allegro API** application.

## Purpose

This application is a private, internal integration used only by the owner of the associated Allegro seller account to manage sales offers through the Allegro REST API.

The integration is used for tasks such as:

- reading offer and sales-setting data,
- creating and editing Allegro offers,
- selecting existing delivery settings,
- uploading offer images,
- publishing and updating offers.

## Access

The application is intended only for the owner's own Allegro account and is not offered as a service to third-party sellers.

## Version

Current application version: **1.0.0**
